## Open Source

### [gpu-roofline](https://github.com/whatsupjones/gpu-roofline) — Cross-Vendor GPU Performance Analysis
The first dynamic roofline model with tension-based performance analysis. Measures burst vs sustained GPU ceilings across NVIDIA, AMD, and Intel from a single Rust binary. No multi-GB toolkit required.

Physics-based simulation engine models thermal, power, and bandwidth tensions. Detects the real sustained ceiling that production workloads actually see — typically 15-30% below the burst numbers that benchmarks report.

`Rust` · `104 tests` · `11 GPU profiles` · `7 WGSL compute shaders` · `Cross-vendor (NVIDIA + AMD + Intel)`

## Proprietary Programs

### Basalt Engine — Flagship
GPU-accelerated data destruction with cryptographic proof of erasure. Hardware-validated across H100, H200, A100, RTX 5090, and ARM64 edge. 23.5 GB/s sustained throughput. < 3 MB memory ceiling at any data volume. Verifiable Destruction Receipts enable third-party audit without signing keys. Ship-ready for compliance-critical environments.

`Rust` · `203 tests` · `7 integration tests` · `4 fuzz targets` · `6 GPU architectures` · `3 provisional patents (141 claims)`
